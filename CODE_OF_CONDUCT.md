# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be respectful and welcoming, whatever someone's background or experience.
- Give and take criticism of code and ideas, never of people.
- No harassment, insults, discrimination or sharing of other people's private information.

## Reporting

If someone's behaviour in an issue, discussion or pull request breaks these rules, use GitHub's **Report content** option on the comment, or contact the maintainer through their [GitHub profile](https://github.com/uniqueabhishek). Reports are handled in confidence.

Maintainers may edit or remove comments, and block people who repeatedly break these rules, as described in the Contributor Covenant's enforcement guidelines.
